# Target engine: Minecraft (NeoForge)

Generate and discuss mechanics for **Minecraft Java Edition** on **NeoForge 26.1** (official Mojang names).

- Prefer registry IDs (`minecraft:oak_planks`, `minecraft:creeper`), datapacks, and Minecraftuuuum lemmas (`{P:place|registry-id=…}`).
- Do not emit Unity C# or Unreal C++.
- Voxel art uses addresses `{artworkId}:{face}:{u}:{v}[:t]`.
- Humanoid actors use MediaPipe Holistic; non-human actors use MoCapAnything v2.
- Wrapper mods bind third-party registry IDs; do not vendor other mods' jars.
